# Zacro interface and motion

The 0.9 interface builds on the earlier [Arc reference and workflow review](DESIGN-REVIEW-0.4.md). Navigation and the address field live inside the sidebar, leaving the page free of a permanent full-width toolbar. The sidebar order is navigation, address, icon favorites, Space identity, folders and saved Space pins, a divider, New tab (the palette), and temporary Today tabs. Its footer contains Library, Space icons and a creation menu. Page actions and secondary tools live in compact menus. The Windows navigation row has no application-logo button, and the sidebar toggle is available through its shortcut and browser commands.

Library first opens a compact menu of bookmarks, history, downloads, archived tabs, Settings, extensions and AI. The panel title doubles as a section chooser. Lists use flat rows, date groups and search; download actions that are used less often live in a More menu. These panels share the Space's continuous chrome material without a vertical dividing line; their compact heading and window-edge placement distinguish them from the webpage card. The native page stays visible and live throughout opening, section changes and closing. Opening Library never captures or substitutes a reduced-resolution JPEG.

The default sidebar is 224px wide and the Library panel is 336px wide. Both have draggable edges with saved widths, keyboard arrow adjustment and double-click reset. Live native page bounds follow a drag without reloading or capturing the page. Existing custom widths remain intact. Comfortable tab rows are 32px high and Compact rows are 28px; the footer is 32px. A raised selected row and hover/focus controls keep other tabs visually quiet, with 16px favicons and readable text. Page inset is configurable from 4–20px, defaulting to 8px, with matching left/right/bottom gutters, including the gap between a page and an open browser panel. macOS and full screen use that inset at the top too; Windows reserves 36px for its window controls, and hidden-sidebar navigation or Find reserves 40px. Corner radius is configurable from square to 20px, defaulting to 12px. The webpage shell and native Chromium bounds/radii share these settings for normal pages, split view and Peek; split panes keep their 6px internal separator.

The minimum window is 560×420. Wide sidebars adapt without changing their saved width. When a panel and sidebar cannot fit beside a 240px page, the sidebar retracts temporarily and returns when the panel closes or the window grows. Panels keep scrollable bodies, and AI's composer area can scroll at short heights. Below a 420px page width, the command palette uses the window's available width. The palette is an opaque floating card with a shadow; it does not blur, tint or change the corner radius of the page behind it, including under Reduce Transparency. Palette results, shortcut rows and theme controls scroll within the available height.

An empty Space opens the command palette without inserting a blank tab. New Tab and Ctrl/Command + T open the same palette; submitting a destination creates a page, while dismissal leaves the tab collection unchanged. Ctrl/Command + L edits the current address. The explicit New Tab Page action opens the home page with search, saved destinations, and recent pages. Pinned pages are omitted from home shortcuts while the sidebar is visible. The crossed-Z icon remains an original vector asset; system fonts use real weight variants.

Each Space has one of 38 searchable built-in icons plus primary and secondary colors, gradient balance, grain from 0–200 and window tint opacity from 0–100. Existing grain values through 100 retain their previous strength. Color swatches remain circular; High Contrast presents named choices. Customize Space previews edits before Save; dismissal restores the saved theme and native material. Below 100% tint opacity, supported windows use desktop acrylic on Windows 11 22H2+ or behind-window vibrancy on macOS. The operating system controls blur strength. Text and web pages stay opaque; this is not whole-window opacity. Unsupported systems, reduced transparency and high contrast use opaque chrome. Selection has an explicit outline and accent edge, including in dark appearance. Layout & motion also offers tab density, motion speed and idle-favorite timing.

Ctrl/Command + S toggles the sidebar; Ctrl/Command + Shift + S saves the page. A compact navigation row appears above the page when the sidebar is hidden, preserving navigation and the address. Sidebar and browser panels share a 220ms monotonic ease-out at Balanced motion, without spring or overshoot. Both shell widths and native page geometry follow the same animation samples. Rapid reversal starts from the current presented widths; reduced motion settles both rails immediately. Pages remain live without reloading or being replaced by screenshots. There is no edge-hover panel. Ordinary profile details live in the Space switcher; private browsing remains explicitly identified.

Scroll horizontally over the sidebar to move between Spaces in the current profile, or hold Shift while using a vertical mouse wheel. Favorites, folders and tabs track displacement together, with the neighboring Space's real sidebar contents entering alongside them. The footer stays in place and no redundant name badge appears during the gesture. The recognizer decides on release: a drag across 42% of the sidebar width or a qualifying velocity-projected flick commits one switch. Direction reversals unwind displacement and can cancel commitment. Endpoints use bounded rubber-band feedback without wrapping. Horizontal intent locks after a small movement; vertical scrolling and diagonal noise cannot become navigation through a sideways momentum tail. Webpage scrolling is unaffected. Each Space remembers its tab-list position. Right-click a footer Space icon for switching, customization, rename, moving the current tab, creation and deletion where applicable; Shift+F10 opens the same menu from keyboard focus.

One uninterrupted wheel stream can commit only once. Explicit contact-end/momentum hints are used when supplied. Without portable native phases, a 110ms pause or conservative sustained deceleration identifies likely release; 240ms of quiet rearms the gesture. These remain heuristics requiring physical-trackpad acceptance on supported Mac versions. Committed gestures settle from their actual displacement over a distance/speed-dependent 140–240ms interval at Balanced motion; cancelled gestures return over 100–200ms. Keyboard and direct Space changes use a 220ms transition. The command palette leaves the sidebar interactive; other dialogs, text inputs, tab dragging, pinch/zoom, pointer exit and window resizing interrupt tracking. A cancelled gesture consumes its remaining tail.

The window's two colors, gradient balance, grain and tint opacity follow the same presented swipe progress. Perceptual color interpolation precedes readable-tone derivation. Reversing retraces the blend; cancellation and commitment use the tab rows' settling clock. An edge with no neighboring Space keeps its original theme. Metadata updates cannot replace a partial blend with the saved theme. Native acrylic or vibrancy remains available until settling completes, with no per-frame host calls or saved-theme changes. Reduced motion removes the settling animation. Opaque tint surfaces have contrast coverage; arbitrary desktop content behind low-opacity chrome cannot carry the same guarantee.

Windows High Contrast uses system colors, explicit selection/focus outlines, native checkboxes and named Space-color choices. Decorative artwork and page snapshots are omitted in forced-colors mode so controls remain distinct.

macOS uses native traffic lights and a native menu bar. The title area reserves the controls' space with the sidebar shown or hidden; full screen removes that reservation until the controls return. The interface uses familiar ⌃⌥⇧⌘ labels, system typography, inactive-window treatment, Finder wording, and system contrast/transparency preferences. ⌘Tab and ⌘H retain their operating-system actions; ⌃Tab traverses recent tabs within the current profile. Close Window and Quit are distinct, with Dock reopening and private-session cleanup. See [the Mac guide](MACOS.md) for the full behavior and verification boundary.

## Motion rules

- Motion uses different timings for different interactions. At Balanced speed, dialog entrances take 140–160ms, microfeedback takes 100–120ms, keyboard Space changes take 220ms, and sidebar/panel rails take 220ms. Gesture settling follows the remaining distance and recent speed. Quick, Balanced, Relaxed and Gentle settings scale presentation; reduced motion overrides them.
- Tab creation, selection, reordering, and folder disclosure use short local movement. Space changes keep their direction and continue from the presented gesture offset. Browser panels slide at a stable expanded width as their reserved canvas width changes; their controls do not squeeze and reflow during the transition. Dialogs enter with restrained opacity and translation. Peek lifts its native page and chrome together by up to 10px while its shadow and surrounding scrim settle; opening takes up to 180ms and closing up to 120ms at Balanced speed. Reversal starts from the current presentation, and reduced motion removes the travel. Focus and controls do not wait for an entrance to finish.
- Closing a panel immediately makes it inert and restores focus, while its chrome slides out. Modal dismissal restores the live page immediately. A new overlay settles any moving chrome before capturing the page so snapshot clipping and native bounds agree. Avoid long fades, large travel distances, repeated animation on metadata updates, and transitions that rescale a live web page.
- State updates reuse unchanged UI sections, preserving focus, search input, scroll position, and ongoing animations.
- Native web pages are laid out only when geometry or visibility actually changes. Ordinary title, history, download, or icon updates must not hide/show an already visible page. Inactive pages detach from the native window hierarchy while their live documents remain available, keeping hidden pages out of platform accessibility navigation without discarding drafts. Modal backdrop capture briefly retains its hidden native surface until capture completes or the 750 ms deadline expires; the command input receives focus immediately. The longer image deadline accommodates cold native compositor copies without delaying the overlay or keyboard interaction.
- `prefers-reduced-motion` disables decorative and transition motion. Switching the preference while a dialog or panel is moving completes its finite transition and focus cleanup. No essential information is communicated only by animation.

## Interaction requirements

The command field follows combobox/listbox keyboard behavior. Results can be filtered to Tabs, Spaces, Folders, Bookmarks, History or Actions; `/` and `>` select actions, `@` selects tabs and `#` selects Spaces. Fuzzy matching uses names, descriptions and action keywords. Tab on a selected result opens applicable actions, followed by a destination chooser for moving tabs; Escape steps back without losing the original query. Page Up/Down traverse longer results. A configured site-search keyword followed by Tab enters a query mode; templates encode the query safely and persist across restarts. Site searches can be added, edited and removed from the command workflow. Repeating the palette shortcut dismisses it. Actions expose Space customization, sleeping unused favorites and prepared AI intents alongside normal browser commands. IME composition must finish before Enter can navigate or send a question. Forms and other modal dialogs isolate background controls, trap Tab, and restore focus to a usable trigger when dismissed. The command palette keeps the sidebar available for tab, Space and navigation actions while protecting the live page behind its backdrop. Its query and results are cleared when the profile changes. Panel searches retain their input and selection during state updates. F6 moves between the web page and browser controls. Split-view navigation and page actions target the focused pane without swapping page positions. Compact menus preserve tooltips, accessible names and keyboard access; secondary tab controls appear on keyboard focus as well as hover.

The shortcut catalog drives host input, native menus, command search and the searchable shortcut editor. Defaults follow Arc's [command and recent-tab model](https://start.arc.net/master-multitasking): Ctrl/Command + T opens commands, Ctrl/Command + D pins, and Ctrl + Tab visits recent tabs. Holding Control freezes the recent-tab order until released; sidebar-order navigation uses pinned tabs, folders and ordinary tabs. Ctrl/Command + Option/Alt + Left/Right switches Spaces, and Control + 1–9 on Mac or Alt + 1–9 on Windows selects a Space directly. Rebinding removes a command's old aliases; resetting validates restored aliases before accepting them. Platform-specific overrides survive restart. The editor preserves system/editing combinations, IME input and AltGr text entry.

The sidebar shortcut keeps focus in the active web-page field when invoked there. Ctrl/Command + Alt/Option + S focuses the sidebar, where arrows traverse tabs and folders and Enter activates them. F6 switches between page and browser controls. A first-run welcome tour introduces commands, sidebar navigation, Spaces, favorites and preferences; every shortcut shown is editable in place, using the same conflict checks as the shortcut editor. The tour can be reopened from browser commands. Library panels return to their opener, and switching Library sections does not lose that return target. Settings disclosures retain their expanded state and input drafts through asynchronous updates.

Manual tab names survive web-page title changes, reloads, and restarts. Shift-click on a link opens Peek, including links that request a new window; the existing Alt-click alias remains available. Ordinary trusted links from a pin to another hostname open Peek, while forms, redirects, prevented clicks, downloads and links with explicit window/relationship semantics keep their native behavior. Leading www is ignored in this comparison; it is not a full registrable-domain match. A page preview keeps its JavaScript state, input, and scroll position when promoted. User-written form state is protected by the existing beforeunload decisions.

Modifier-click interception currently covers links in the main document. Embedded iframe links retain Chromium's native click behavior; the link context menu still offers Peek. Extending interception to frames requires an isolated, document-validated per-frame path. Inferring a click from a later navigation event would also catch forms and scripts and is not used.

Favorites are profile-wide icons backed by one live page across Spaces. Space pins are durable rows and can belong to folders. Pinning saves the original address and title; page navigation does not rename that destination. Favorite tiles activate their existing page. A Space pin favicon or explicit Reset Tab returns to the saved address; clicking the pin title activates the current page. A forward slash indicates a pin away from its saved address. Replace Pin deliberately updates the saved address. Closing either keeps its name, saved address and position, marks it Closed and releases its native page after any unsaved-work decision. Activating it opens a fresh page. Loaded, Sleeping and Closed remain available in tooltips and accessible names; no status dot is drawn beneath the favorite icon. Idle favorites can sleep after a configurable interval, defaulting to 20 minutes, or through an explicit action. Active/split/Peek-source pages, media/capture, pending authentication, downloads and detected edits block sleeping. An isolated DOM inspection conservatively keeps changed fields, editing surfaces and unreadable frames awake; beforeunload vetoes automatic unloading silently. Sleeping discards runtime state and reloads on activation, so protections do not imply that every website's arbitrary in-memory state can be detected.

Favorites fill balanced rows of one to four 46px-high tiles: five uses three plus two, six uses three plus three, and nine uses three rows of three. Every row fills the resized sidebar width. Larger collections scroll within a region bounded by 176px or 35% of the available Space area. Unpinning an open page returns it to Today; unpinning a closed saved item removes it.

Today tabs auto-archive after 12 hours of inactivity by default. The primary profile sets the shared default; other profiles can inherit it or choose their own interval, including Never. Existing explicit choices survive upgrades. Viewing a tab resets inactivity, including time recorded across normal restarts. Clean loaded background pages can now archive after the same conservative draft, media, download, authentication and beforeunload checks used for safe unloading. Active pages, visible split panes, Favorites, pins and folder tabs stay protected, and eligibility is rechecked after asynchronous inspection. Archive restores ordinary browsing tabs; private sessions retain their nonpersistent behavior. This policy cannot detect every site's arbitrary in-memory state.

AI starters prepare summaries, explanations, comparisons or research questions without sending. Context chips identify the explicitly granted document titles/URLs; selecting another active tab does not change them. A navigated/closed document requires review or removal before the next send, and backend history scopes include document URLs. Each user turn records its context. Edit restores a request for review; Retry sends only on a deliberate click; Copy includes answer text, warnings and returned sources. Drafts survive panel changes, streams and retries within a profile, including hidden-panel handling, but do not cross profiles. Enter sends and Shift+Enter adds a line. Partial answers remain marked incomplete, and request IDs prevent a cancelled/reset turn from reappearing. See [AI.md](AI.md) for provider limits and data boundaries.

## Reproducible review

The [capture record](screenshots/README.md) identifies each gallery and feature guide by its exact application revision. `node scripts/review-captures.cjs --opaque` prepares an isolated packaged application through test instrumentation and waits for a stage name on stdin. Computer captures the resulting whole window separately. The harness saves source-package hashes and stage geometry; it does not generate or retouch images. Instrumented gallery states and native pointer/keyboard review have distinct provenance.

`npm run test:interactive` launches the browser with a fresh disposable profile and a local journal fixture. Add `-- --showcase` for a populated design-review workspace, or `-- --packaged --showcase` to inspect the packaged executable. Add `--compact` for minimum-size review and `--onboarding` for the editable tour. The showcase uses prepared demo tabs and bookmarks; only the local active page loads initially. Its Mail, Calendar, Notes and Studio favorites open local demo pages with original PNG icons; visit each once to load those icons through Chromium. The fixture includes navigation, a second article, a page-local draft/counter, popup links, and a small download. Close the browser when finished; the launcher removes only its own temporary profile. A manually downloaded test file uses the browser's normal Downloads directory.

`npm run test:e2e` checks real Chromium interactions, focus restoration, sampled text contrast in light/dark themes, reduced motion, responsive layout, native page bounds, and profile boundaries. `npm run test:soak` repeats tab/Peek/split lifecycles, verifies that closed native pages are released and the original draft/reading position survives, and writes resource observations to `test-results/soak.json`. These checks supplement hands-on Windows review; they do not replace a full assistive-technology, real-site, or long-running performance evaluation.

The [validation record](VALIDATION.md) separates focused regressions, full-suite runs, package checks and platform acceptance by revision. Earlier screenshots, PDFs and CI results remain historical evidence for those revisions. Still images establish layout; they do not establish physical Mac motion, live-provider acceptance or commercial release readiness.
