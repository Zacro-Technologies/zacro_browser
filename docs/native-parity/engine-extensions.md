- Retained Chrome-style documents and isolated persistent/incognito request contexts; no Alloy or WebKit substitution.
- Process-local DevTools JSON calls, bounded responses/deadlines, cancellation, isolated-world extraction, and authenticated document resource requests through the document's actual CEF request context. No debugging socket or privileged webpage binding.

- Browser/window termination and beforeunload cancellation, asynchronous service shutdown, profile retirement journaling before safe database removal, and retained document promotion.

- Extension registry/permissions/enabled state/pinning/icons/options/commands/reload/install/update/uninstall operate against Chromium's trusted internal management document. Structured Chromium errors propagate to the native UI.
