# Internal integration contract

The desktop application uses CommonJS on Node/Electron and plain ES modules in its isolated UI. Remote pages have no application bridge. `src/main/main.cjs` is the entry point; `src/main/preload.cjs` exposes only `window.zacro.invoke(action, payload = {})`, `window.zacro.onState(callback)`, `window.zacro.onEvent(callback)` (both return unsubscribe functions), and `window.zacro.platform`.

`src/core/store.cjs` exports `BrowserStore`, `normalizeAddress`, and `createInitialState`. `new BrowserStore(directory)` loads state. `.state` is the current state, `.dispatch(action,payload)` applies a synchronous mutation and returns a result, `.snapshot()` clones the current state, `.save()` persists atomically, and `.flush()` is available on quit. `.on('change', callback)` notifies subscribers. The main process may update `.state` then call `.changed()` for runtime-managed downloads/extensions. State is JSON serializable.

State: `{version:1, profiles:[{id,name,private:false}], spaces:[{id,profileId,name,color,icon}], activeSpaceId, activeTabId, tabs:[{id,spaceId,profileId,title,url,pinned,folderId:null,createdAt,lastActiveAt}], folders:[{id,spaceId,name}], history:[{id,profileId,url,title,visitedAt}], bookmarks:[{id,profileId,url,title,createdAt}], archive:[], downloads:[], extensions:[], permissions:[], settings:{theme:'system',searchEngine:'duckduckgo',archiveAfterHours:24,sidebarWidth:230,restoreSession:true,openSourcesLimit:3,aiProvider:'codex',aiModel:'',sharePageContext:false}, windowBounds:{width:1440,height:940}}`. Times are epoch milliseconds. New tabs use `zacro://newtab`. Default profile id is `default`. Default Space id is `home`.

Core mutations (payload keys): `tab:create {url?,spaceId?,active?}`, `tab:activate {id}`, `tab:close {id}`, `tab:pin {id}`, `tab:move {id,spaceId?,folderId?,index?}`, `tab:update {id,url?,title?}`, `tab:restore {id?}` (archive), `tab:archive-stale {now?}`, `space:create {name,color?,profileId?}`, `space:update {id,name?,color?,icon?}`, `space:activate {id}`, `space:delete {id}`, `profile:create {name,private?}`, `profile:delete {id}`, `folder:create {name,spaceId?}`, `folder:update {id,name}`, `folder:delete {id}`, `bookmark:toggle {url?,title?,profileId?}`, `bookmark:delete {id}`, `history:add {url,title,profileId}`, `history:clear {profileId?}`, `archive:clear {profileId?}`, `settings:update {values}`, `permission:set {profileId,origin,permission,allowed}`, `permission:clear {profileId?}`. Create returns the created record. Other mutations return null or the changed record. Closing a pinned tab unpins? No: explicit close removes it and adds to archive. Never automatically archive pinned tabs. Deleting last profile/Space is rejected. Move tabs only within same profile.

Main-process actions also include `state:get`, `navigate {url}`, `back`, `forward`, `reload`, `stop`, `window:minimize`, `window:maximize`, `window:close`, `layout {sidebarWidth?,panelWidth?,overlay?,peek?}` (UI sends overlay=true for dialogs to hide native web views), `find {text,forward?,findNext?}`, `find:stop`, `zoom {delta? reset?}`, `print`, `devtools`, `split:toggle {id?}`, `peek:open {url}`, `peek:close`, `peek:promote`, `download:show {id}`, `download:cancel {id}`, `download:pause {id}`, `download:resume {id}`, `download:rename {id,name}`, `download:undo {id}`, `data:export`, `data:import`, `data:clear {profileId}`, `extension:install`, `extension:remove {id}`, `extension:toggle {id}`, `external:open {url}`, `app:about`.

Snapshot extends store state with `runtime:{page:{loading,canGoBack,canGoForward,error?,zoom?},splitTabId:null,peek:null|{url,title,loading},platform,version,aiConfigured:false,aiBusy:false}`. Runtime may include `pages` map keyed by tab id. Host sends state via `zacro:state` and events `{type,...}` via `zacro:event`. Event types: `command {mode?}`, `panel {panel:'history'|'downloads'|'bookmarks'|'settings'|'ai'|'archive'|'extensions'}`, `find`, `toast {message}`, `ai:answer {answer,sources:[{url,title}],...}`, `ai:error {message}`, `ai:progress {message}`. UI handles initial state via `state:get`. Keyboard shortcuts work both in remote contents and shell.

AI service at `src/main/ai.cjs` exports `AIService`: constructor `{getState, getPageContext: async(ids)=>[{id,title,url,text}], emit:(event)=>void, userDataPath, openExternal, client?}`. `.handle(action,payload)` supports `ai:login`, `ai:login-cancel`, `ai:configure {model}`, `ai:disconnect`, `ai:ask {question,tabIds?:[],usePageContext?:boolean}`, `ai:cancel`, `ai:reset`, `ai:status`, and `ai:suggest-name {id,name,url,title}`. The `ai:status` action refreshes the connection. `.status()` exposes cached connection availability, configured/account/model state, login progress and request state; tokens are never exposed. `.latestSources` contains validated evidence URLs; the host handles `ai:open-sources` with active-profile checks and tab reuse.

The main-process `CodexClient` in `src/main/codex.cjs` owns the pinned app-server over stdio, a Zacro-specific home/workspace and OS keyring credential entry. Sign-in opens the validated official ChatGPT authentication URL through `openExternal`. API credentials and legacy credential imports are rejected. Inference occurs only after an explicit question or filename request; no automatic page sharing. Shared tab IDs must belong to the active, non-private profile. Research enables hosted web search; page/PDF questions and filename suggestions disable it. Threads are ephemeral and both thread/turn calls explicitly select no execution environments, with never-approve/read-only restrictions and fail-closed tool handling. UI provides sign-in, cancel sign-in, refresh, model choice, disconnect, research/current-page/selected-tab context, follow-ups, stop, reset and source opening. Live account acceptance is separate from mocked protocol verification; there is no API billing fallback.

## Interface additions in 0.2

Tabs may carry `customTitle`; an explicit user rename controls the displayed `title` while the native document title remains available for history/context. Window bounds also retain validated monitor coordinates and `maximized`. Old version-1 state remains compatible.

`runtime.pages[id].favicon` is a bounded, optional PNG/ICO data URL from `FaviconLoader`, never an external image URL or persistent record. The `page:backdrop {frames:[{bounds,dataUrl}]}` event carries temporary JPEG presentation frames while a modal is open; an empty frames array clears them. Consumers must reject late frames when no modal is open and must not show frames in private profiles.

`focus:chrome` asks the renderer to focus its address control; `page:focus` is a shell-only action to return focus to the active native page. F6 uses this cycle. The shell handles composition events and dialog focus locally. Native layout is calculated in `src/main/layout.cjs`: toolbar height 44, page corner radius 10, outer right/bottom inset 8, split gap 6. A hidden sidebar sends width 0 and leaves an 8-pixel left inset. Panel layout reserves an additional 8-pixel gap between page and panel.

## Interface additions in 0.3

The default sidebar width is 230; saved user widths remain valid. The renderer handles `sidebar:toggle {fromPage}` and returns focus through `page:focus` when the shortcut originated in a native page. Library is a compact chooser whose panels share section navigation and preserve their opener for focus return. Settings uses persistent disclosure state. Dialog and panel entrances are short; dismissal and native-view geometry updates are immediate.
