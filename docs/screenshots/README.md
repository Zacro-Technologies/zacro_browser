# Screenshot assets

These images were captured from the packaged Zacro 0.3 Windows application on October 24, 2026 using the Computer plugin for both the final interactions and native window captures. They show the implemented interface with a prepared demo profile and locally served journal pages. They contain no real account credentials, private browsing history, or simulated AI answers.

The captures are JPEG images, preserved without recompression. The blue pointer highlight belongs to the Computer capture tool and is preserved in the images. The filenames describe the visible feature:

- `home-dark.jpg`: minimal dark launchpad, bookmarks and recent pages.
- `appearance-light.jpg`: light appearance with compact Settings open.
- `workspace.jpg`: dense sidebar with icon favorites, folders and tabs beside a live page.
- `peek.jpg`: the native link preview.
- `split-view.jpg`: two native pages side by side.
- `command-palette.jpg`: tab search over the temporary page backdrop.
- `bookmarks.jpg`: the searchable Bookmarks panel and Library switcher.
- `focus-mode.jpg`: the live page with the sidebar hidden.
- `optional-ai.jpg`: Ask Zacro before ChatGPT subscription sign-in.

Screenshots are still images. See [design and interaction notes](../DESIGN.md) for motion, keyboard and accessibility behavior, and [release status](../ROADMAP.md) for unfinished product requirements.

Reproduce the demo with `npm run test:interactive -- --packaged --showcase` after packaging. Reference images used during the design study are linked in [the review](../DESIGN-REVIEW-0.3.md); they are not included in these application captures.
