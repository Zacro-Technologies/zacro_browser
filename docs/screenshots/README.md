# Screenshot assets

These images were captured from the packaged Zacro 0.2 Windows application on October 24, 2026 using the Computer plugin. They show the implemented interface with a prepared demo profile and locally served journal pages. They contain no real account credentials, private browsing history, or simulated AI answers.

The captures are JPEG images, preserved without recompression. The filenames describe the visible feature:

- `home-dark.jpg`: home, favorites, folders and recent pages.
- `appearance-light.jpg`: light appearance with Settings open.
- `workspace.jpg`: sidebar organization beside a live page.
- `peek.jpg`: the native link preview.
- `split-view.jpg`: two native pages side by side.
- `command-palette.jpg`: tab search over the temporary page backdrop.
- `bookmarks.jpg`: the searchable Bookmarks panel.
- `optional-ai.jpg`: Ask Zacro with no provider connected.

Screenshots are still images. See [design and interaction notes](../DESIGN.md) for motion, keyboard and accessibility behavior, and [release status](../ROADMAP.md) for unfinished product requirements.
