Archive URLs, platform labels, byte counts, digests and upstream object metadata are recorded in `engines.lock.json` in this experiment's root. A matching digest establishes the downloaded file's identity against the recorded source; it does not establish Google acceptance, code-signing identity or a local source build. Keep the generated assembly manifest with each runnable artifact.

The snapshot is a development build three Chromium major versions newer than the Brave reference and existing Electron runtime. Preserve that difference in reports. The same source commit for Windows and Mac does not prove that their compiled behavior or OS capabilities are identical.

Local evidence is retained separately: [Windows Chromium startup failure](../evidence/mechanics-chromium-win32-x64-engine-only.json), [Windows Brave local mechanics](../evidence/mechanics-brave-win32-x64-reference.json) and [human reference acceptance](../evidence/manual-reference-results.json). The snapshot's failure occurs before document startup and must not be described as a Google rejection. The source candidate uses Chromium 156 to align the engine version, but its behavior remains untested until a real build is available.
